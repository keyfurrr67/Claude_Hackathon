      What the terms mean

      Close approach
      Two objects are predicted to pass near each other. Each one is an event in the queue.
      Warning message
      An update on that prediction. One event usually gets several as it gets closer. Operators call these CDMs.
      Closest approach
      The moment the two objects are nearest. Operators call this TCA.
      Miss distance
      How far apart they are predicted to be at closest approach.
      Collision probability
      The chance they actually hit. Operators call this Pc. The brief treats 1 in 10,000 or higher as Critical.
      Worst-case estimate
      Roughly the highest the collision probability could be, given the tracking uncertainty. It comes with each message.
      Chance Critical
      The model's calibrated probability that this message belongs in the Critical tier.
      Needs review
      The system is unsure or the data is poor, so a person should check it whatever the tier says.
      Overall score
      Macro F1, from 0 to 1. It averages accuracy across all three tiers, so rare Critical rows count as much as Safe ones.
